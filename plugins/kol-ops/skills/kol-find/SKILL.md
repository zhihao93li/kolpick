# 找 KOL

先读 `${CLAUDE_PLUGIN_ROOT}/reference/rules.md`。

需要 Apify token，只存在这台电脑上：`~/.kol-ops/apify-token`（或环境变量 APIFY_TOKEN）。没有就请同事向项目负责人要，自己存进去；不要把 token 贴进对话或写进任何文件以外的地方。

1. 和同事确认：平台（instagram / youtube / tiktok）、找法（关键词 `--keywords`、对标账号 `--seeds`、或直接给账号 `--handles`）、粉丝范围、大约搜多少个账号（`--target`，会平分给各关键词和对标账号；有公开邮箱的通常是三到四成）、预算（美元）、入库批次名。入库批次还不是选项的，同事同意后加 `--add-batch`，插件会在「入库批次」里加上。也可以请同事直接在决策台的「找新人」里填。
2. 试跑：

   ```bash
   node "${CLAUDE_PLUGIN_ROOT}/scripts/kol.mjs" find --platform instagram --keywords 親子,育兒 \
     --min-followers 5000 --max-followers 200000 --budget 20 --batch <入库批次> --job <这次的名字> --dry-run
   ```

3. 讲清楚参数和预算上限，同事同意后去掉 `--dry-run`。会跑一阵子，跑之前告诉同事。
4. 汇报：新入库几人、其中有邮箱几人、跳过多少（已在库里、不符合条件）、花了多少钱、是否因预算提前停。
5. 中途断了用同一个 `--job` 名重跑，已完成的 Apify 步骤不会再花钱。

找到的人直接进档案，没有额外的筛选步骤；没邮箱的也入库，免得下次重复花钱。

## 补全档案（找完就做，不用等同事说）

新入库的人没有合作邀约方向、市场、語言、内容类型和称呼，不补就没法按方向挑人、配模板，信里的称呼也会变成账号名。

1. `node "${CLAUDE_PLUGIN_ROOT}/scripts/kol.mjs" classify --batch <入库批次>`：列出这批还缺字段的人（每次最多 50 位，`--limit` 可改），附简介、粉丝数和每个字段能选的值。
2. 按简介、账号名称和主页链接判断每个人，写成一个 JSON 文件，格式是 `{"rec…": {"合作邀约方向": "亲子", "市场": "台湾", "語言": "繁體中文", "内容类型": "亲子家庭", "称呼": "小鹿"}}`：
   - 选项只能用结果里「可选值」的名字；拿不准就选「待確認」，没有这个选项就不填这个字段。
   - 称呼是信里怎么叫对方：简介里有名字就用名字，没有就用账号名称里像名字的部分，不要带 @ 和表情。
   - 明显不是个人创作者的（品牌店、官方号、私人账号）不用补，在汇报里点出来，请同事决定要不要把联系许可改成「永不联系」。
3. `classify --apply <文件>` 写入。它会先逐个校验，有一个值不对就一条都不写，并列出问题；改好再跑。
4. 名单超过 50 位就重复 1–3 步，直到「还要补的人数」是 0。
5. 汇报：补了几位，各方向几位，「待確認」的有谁，哪些看起来不是个人创作者。

补完要发邀约就接着用 kol-invite。
